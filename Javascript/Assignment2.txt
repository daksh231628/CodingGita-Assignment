/*
----------------------------------------------------------------------
Question 9: Predict and Explain
Without running the code, predict the output of each `console.log()` 
and identify which lines cause errors. Explain your answer using the 
rules of scope, re-assignment, and variable declaration.

Code given:
var x = 10;
if (true) {
    var x = 20;
    let y = 30;
    const z = 40;
}
console.log(x);
console.log(y);
console.log(z);
----------------------------------------------------------------------
Prediction and Explanation:
1. `console.log(x)` -> Outputs: 20
   Explanation: `var` is function/global scoped, not block scoped. 
   Inside the `if` block, `var x = 20` re-declares and overwrites 
   the global `x`.

2. `console.log(y)` -> Throws: ReferenceError: y is not defined
   Explanation: `let` is block scoped and only exists within the 
   `if` statement's `{}` block.

3. `console.log(z)` -> Execution stops at line 2 error, but would throw: 
   ReferenceError: z is not defined
   Explanation: `const` is also block scoped and inaccessible outside `{}`.
----------------------------------------------------------------------
*/


/*
----------------------------------------------------------------------
Question 10: Fix the Program
The following program contains multiple errors. Fix the code so that 
it runs correctly. Make sure your solution follows the rules for 
initialization, re-declaration, re-assignment, and scope.

Code to fix:

    var city = "Delhi";

    var fixedCity = "Delhi";
